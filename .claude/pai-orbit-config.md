## Deploy

Provider: none — git/marketplace-based release (no cloud deploy)

This repo is distributed via the Claude Code plugin marketplace and adapter dist/ bundles,
not deployed to a runtime environment. "Release" replaces "deploy" here:

Release steps:
| Step | Command |
|------|---------|
| Bump version | Update `plugins/pai-orbit/core/plugin.json` (`version`) and README/CLAUDE.md version references |
| Rebuild all adapters | `bash plugins/pai-orbit/build.sh` |
| Verify dist | Review `git diff` under `plugins/pai-orbit/dist/` — never hand-edit these files |
| Commit | Commit core changes + regenerated `dist/` together |
| Tag (optional) | `git tag vX.Y.Z && git push --tags` |
| GitHub release (optional) | `gh release create vX.Y.Z` |

Auth check command: n/a — no cloud credentials required

in a target project (`/plugin marketplace add`, `/plugin install`) and smoke-testing a mode.
