## Findings

### Blocking
- [x] **FIXED** (`3f554dd`) `.claude/settings.json`:5,9 — Both hook commands are hardcoded to `/home/anurag/workspaces/pai-orbit/.claude/hooks/{bash-guard,arch-drift-guard}.sh`, an absolute path specific to the PR author's local checkout. On any other machine (another contributor, CI, a fresh clone) this path won't exist, so Claude Code will fail to find the hook and both hooks — including the force-push and bulk-staging denies in `bash-guard.sh` — will effectively be disabled with no visible error. Use a path relative to the repo root (Claude Code hook commands support `${CLAUDE_PROJECT_DIR}`, or a relative path resolved from the project root) so the hooks work from any checkout. Follow-up commit `3f554dd` replaces both paths with `${CLAUDE_PROJECT_DIR}/.claude/hooks/...` and was pushed to `chore/orbit-self-setup`.
